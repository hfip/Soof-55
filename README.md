# Soof-55

إضافة Stremio لموقع شوف لايف، تعمل على **Vercel** أو **VPS**.

## الميزات

- كتالوجات آخر الحلقات والمسلسلات والأفلام، مع البحث.
- صفحات المحتوى وقائمة الحلقات من الموقع نفسه.
- اكتشاف قائمة سيرفرات Alba تلقائيًا بدل تثبيت `serv=2` أو `serv=3`.
- استخراج MP4 وHLS، وقراءة الجودات من قوائم HLS الفعلية.
- فك Packer كبيانات دون تنفيذ `eval`.
- اختيار الحلقة برقم الموسم والحلقة عندما يذكرهما الموقع؛ الحلقات التي لا يذكر الموقع موسمها تُعامل كموسم أول.
- كاش محدود الحجم وتجميع الطلبات المتطابقة، مع `/health` للمراقبة.
- روابط مباشرة على Vercel، وبروكسي MP4 اختياري بتوقيع ومدة صلاحية على VPS.

## النشر على Vercel من GitHub

1. من حساب Vercel اختر **Add New → Project** ثم استورد مستودع `Soof-55`.
2. اختر **Framework Preset: Other** واجعل Root Directory جذر المستودع.
3. اترك Build Command بدون أمر مخصص؛ إعدادات وظائف Node والمسارات موجودة في `vercel.json`.
4. أضف `TMDB_API_KEY` في Environment Variables إذا أردت استخراج البث لمعرفات IMDb مثل `tt...` المستخدمة في Cinemeta. كتالوج الإضافة ومعرفاته الخاصة لا يحتاجان المفتاح.
5. اضغط Deploy، ثم افتح `https://YOUR-PROJECT.vercel.app/manifest.json`.
6. في Stremio → Addons الصق رابط `manifest.json` لتثبيت الإضافة.

متغير `SHOOF_BASE` اختياري، وقيمته الافتراضية `https://w8.shooflive.cyou`. تغييره يسمح بتحديث نطاق الموقع دون تعديل الكود. لا تضع `.env` أو مفاتيح أو نتائج تحتوي روابط موقعة في GitHub.

كل دفع لاحق إلى الفرع الرئيسي يعيد النشر تلقائيًا بعد ربط مستودع GitHub بـVercel.

## حدود التشغيل على Vercel

Vercel يشغّل واجهات الكتالوج والميتا واستخراج الروابط. الفيديو يُطلب مباشرة من سيرفر المصدر، مع `behaviorHints.proxyHeaders.request` و`notWebReady` عند الحاجة للترويسات. توافق هذه الترويسات يعتمد على تطبيق Stremio والمشغّل؛ نجاح استخراج الرابط لا يضمن التشغيل على كل الأجهزة، خصوصًا Stremio Web.

البروكسي الذي يمرر ملفات MP4 الكبيرة ليس وظيفة Vercel في هذا المشروع. إذا احتاج المشغّل إليه، شغّل النسخة نفسها على VPS واضبط `PROXY_BASE_URL` في Vercel على عنوان HTTPS للـVPS، واضبط `PROXY_SECRET` بالقيمة نفسها في الطرفين. HLS يبقى مباشرًا؛ لا يوجد بروكسي لمقاطع HLS أو مفاتيح التشفير في هذه النسخة.

## التشغيل على VPS

يتطلب Node.js 22.14 أو أحدث:

```sh
npm ci
cp .env.example .env
# عدّل .env بالإعدادات المطلوبة
npm start
```

أو باستخدام PM2:

```sh
pm2 start ecosystem.config.cjs
pm2 save
```

المنفذ الافتراضي `7040`. استخدم reverse proxy مع HTTPS إذا أردت استعماله من Stremio Web أو كبروكسي منفصل لنسخة Vercel.

للبروكسي الاختياري:

- `PROXY_BASE_URL`: عنوان VPS العام عبر HTTPS.
- `PROXY_SECRET`: قيمة عشوائية قوية من 32 حرفًا على الأقل؛ يمكن توليدها بـ`openssl rand -hex 32`.
- `MEDIA_HOSTS`: قائمة نطاقات CDN المسموحة، افتراضيًا `cdnz.quest`. أي نطاق آخر يحتاج إضافته بعد التحقق منه.

مسار `/proxy/mp4` يقبل رمزًا موقعًا فقط؛ لا يقبل روابط حرة من المستخدم. يدعم `GET` و`HEAD` وطلبات `Range`، ويلغي اتصال المصدر عندما يغلق المشاهد الاتصال. تفحص وجهات إعادة التوجيه أيضًا.

## التحقق والاختبار

```sh
npm run check
npm test
npm run probe -- 'https://w8.shooflive.cyou/episode/رابط-الحلقة/'
```

أداة `probe` تستخرج الروابط وتطلب جزءًا صغيرًا من ملفات MP4 أو قائمة HLS. تحفظ النتائج في `probe-results.json` المستثنى من Git. اختبارها يتحقق من البنية والوصول إلى البيانات، وليس تشغيل الحلقة كاملة في مشغّل Stremio.

البحث عبر IMDb محافظ: لا يختار أول نتيجة تلقائيًا عند اختلاف العناوين أو غموض المطابقة. قد لا توجد مطابقة عندما يختلف اسم العمل أو ترقيم الحلقات بين TMDB والموقع. كتالوج الموقع ومعرفاته الخاصة يوفران وصولًا مباشرًا للمحتوى الموجود فعليًا.

## الهيكل

```text
api/index.js       واجهات Stremio وVercel
lib/source.js      البحث والمحتوى واكتشاف السيرفرات واستخراج الروابط
lib/cache.js       الكاش وتجميع الطلبات والتحكم في التوازي
lib/proxy.js       بروكسي MP4 الموقع، للـVPS فقط
server.js          خادم VPS
scripts/probe.js   اختبار روابط المصدر
test/             الاختبارات المحلية
```
